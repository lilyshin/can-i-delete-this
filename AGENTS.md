# Cross-runtime install

Codex, Copilot CLI and Gemini CLI look in `~/.agents/skills/`.

    git clone https://github.com/lilyshin/can-i-delete-this
    mkdir -p ~/.agents/skills
    ln -s "$PWD/can-i-delete-this/skills/can-i-delete-this" ~/.agents/skills/

Claude Code users should install through the marketplace instead. See README.
